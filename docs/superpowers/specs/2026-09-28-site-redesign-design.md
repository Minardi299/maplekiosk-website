# MapleKiosk site redesign — design

Date: 2026-09-28. Status: approved in the brainstorming session (landing page, isometric plans, detailed models).

## Goal

Redesign every page of the site. Keep the message that is in the working tree ("Complete by design. Modular by choice.", keep your register, 0%* in person, restaurants and salons get equal space). Replace the look with a simple, elegant and playful one that does not read as a SaaS template.

## Visual language: the drawing set

The site reads like a set of technical drawings of a shop: thin ink lines, sheets with a head row and a title block, numbered red markers, mono labels, and isometric line-art models.

### Colors (from maplekiosk.ca only)

| Token | Value | Use |
|---|---|---|
| cream | `#faf7f2` | page background |
| sand | `#f3ede4` | muted surfaces, left faces |
| line | `#e8e1d7` | hairlines, right faces |
| ink | `#1d1a17` | text, strong rules, dark bands |
| muted | `#6b645c` | secondary text |
| red | `#c0392b` | primary, markers, accents |
| red-2 | `#a8291b` | primary hover |
| amber | `#e07b4a` | rare secondary accent |
| white | `#ffffff` | sheets, drawings |

This replaces the default shadcn neutral palette (2026-08-30). The old site's styling (Playfair, blobs, glass, grain) is not used.

### Type

Bricolage Grotesque for headings, DM Sans for body, DM Mono for labels and numbers. Caveat stays only for the handwriting on the reservation-pad vignette. Be Vietnam Pro stays as the Vietnamese fallback.

### Never use

Gradients, gradient text, neon globs, glassmorphism, glowing orbs, bento grids, feature cards, rounded floating containers, particles, heavy blur, fade-up reveals, pill buttons, decorative grid backgrounds.

### Building blocks

- **No eyebrows** (user, 2026-09-28: "stop expounding"): no kickers or labels above headings, no explanatory sub-lines under headings, no decorative captions, no drawing head rows or title blocks. The Apps menu lists app names only.
- **Section heading**: Bricolage 46px desktop, tight tracking.
- **Buttons**: 6px radius, 48px tall. Variants: red (primary), ink, line (1px ink border), inverted (on ink bands).
- **Sheet**: white panel, 1.5px ink border, a mono head row, optional title block row.
- **Numbered rows**: mono red number, heading, body, hairline between rows. Replaces every card grid.
- **Ink band**: dark full-width band for the final call to action.
- **Red band**: the full-width "0%*" band.
- **Circle markers**: 28px red circles with a white number (a map marker, not a pill button).

### Motion

Motion must carry meaning: a tile drops into its slot, a money line flows, a module turns red when selected, a crossfade in the detail column. No scroll-triggered fade-ups. Every animation has a `prefers-reduced-motion` fallback. The existing timeline draw-in and underline sweep may stay. The kitchen-ticket and money-diagram slide-in reveals are removed.

## Isometric models

- Vector line art generated by `tools/iso/*.py` (Python 3, no dependencies). Flat faces: top white, left sand, right line. Ink 1px strokes that do not scale.
- Detailed models with recognizable shapes and screen content (approved: kiosk, kitchen screen, phone). Every other object is redrawn at the same level: register, counter tablet, customer display, TV boards, delivery bags, stamp card, card terminal, tablets, insights monitor, restaurant furniture, salon stations.
- Screen text in the SVGs is language-neutral (numbers, symbols, "#041", "$13.95", "✓"). Words that visitors must read are HTML overlays drawn from the string files, so all four languages work.
- Output:
  - `public/iso/<name>.svg`: static figures, used with `<img>`.
  - `src/components/iso/scenes/<name>.ts`: interactive scenes (hero board, restaurant plan, salon plan) as `{ svg, markers, labels }`, with positions in percent of the drawing.

### `/booking` (was `/assistant`)

The AI phone assistant page. Structure taken from the ElevenLabs conversational AI page, rewritten for restaurants and salons, with no ElevenLabs facts or numbers:

1. Hero with the phone figure and a big "Call it yourself" call button (`SITE.assistantPhone`).
2. Before / with the assistant table.
3. How it works in three steps.
4. What it does (capabilities as numbered rows).
5. For restaurants / for salons.
6. It says it is automated (disclosure, Law 25 note).
7. FAQ.
8. Final call band with the phone number again.

Claims that are not confirmed (hours, handoff to staff, text messages, transcripts, other languages, data storage) are left out. Update 2026-09-29: the user asked for no placeholders anywhere.

### `/demo` (new, replaces `public/shop-demo`)

Flat, in-page demo in all four languages. A mode switch: café & restaurant, salon.

- Café mode: the kiosk or the counter takes an order, "Charge" sends it to the kitchen screen, "Bump" marks it ready and the customer screen shows it, "86" on an item greys it out on the TV board and the kiosk, and picking a customer shows their stamps.
- Salon mode: "Play a call" runs a scripted call that ends with a booking in the day calendar. Checking out a client with a tip updates the staff payroll row.
- An event log in mono under the screens. A big "Call the real assistant" button.
- On phones, the screens stack in one column, in flow order (input, kitchen, customer screen, TV board, log).

## Copy rules (unchanged)

Problem first. Never promise a POS replacement. Every "0%" has an asterisk and the `zeroNote`. No invented numbers, testimonials or names, and no placeholders: an unknown fact means the claim is left out.

## i18n

Every new string goes into `en.ts`, `fr.ts`, `vi.ts` and `ru.ts` with the same keys.

## Out of scope

A salon-specific pricing change, new legal text, real screenshots, the French-first decision (Bill 96).
